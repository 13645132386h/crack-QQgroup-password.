# qq-python-
脚本通过坐标控制鼠标和键盘来完成穷举测试，很表面
在运行之前，需要在pycharm终端里输入pip install pyautogui，来安装第三方库，开魔法能更快安装，maintext是脚本，在运行代码后有3秒的时间来打开填写群号密码的窗口，需要获取鼠标坐标才能执行，获取鼠标坐标的脚本在2text，同样运行后有3秒的时间来打开窗口，maintext的CLICK_ONCE_POS = (0, 0)，这个是对应发送按钮的坐标，DOUBLE_CLICK_POS = (0, 0，这个是对应输入密码框内的坐标，原理是通过双击和后续的删除键快速填写密码，注意，极限好像是500次，500到600之间之间会弹出提示，600次会把qq弄得限制了，不过好像仿真人的才能500次，不仿真人的100次就不能了好像，main2text是仿真人的代码，不过时间要长一点，因为我也不清楚，所以两个脚本都放上去了，你们可以挨个试试，这个脚本其实就是碰碰运气，有4位数密码的组合是1w种变化，如果你正好想加入的群聊密码是3位数，那成功的概率还是很大的，默认是4位数来穷举，如果是3位数，在代码里把最大值改成999就行，另外，我这有个现成的4位数密码群号，765461814，我用ai写这个脚本的初衷也就是穷举这个密码，如果你们有兴趣碰碰运气或者实践一下可以试试，群里面的这这就是我
